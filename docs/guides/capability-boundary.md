# 能力边界

## 微信：工作输入与数字菜单

普通文字、图片和文件会持久化后送入当前 Codex 目标。发送 `0`、`菜单`、`Codex`、`Codex 菜单`、`Codex Link` 或 `codex-link` 打开数字菜单。

首页 `1–6` 为新建对话、切换会话、工作空间、会话状态、最近结果、回复设置。列表每页四项，`7/8` 翻页、`0` 首页、`9` 退出。正常一次一张图，不可用时回退同编号文字。打断、重跑、重发与锁定使用数字确认页。

常用操作直接在微信完成。结果文字按 500 字分页，解锁码只用于解锁。编号十分钟过期，按展示时的业务 ID 绑定；重复消息不会再次执行副作用。普通工作内容会退出菜单并提交；菜单退出后的普通数字可以作为任务，`0` 保持快捷入口。带附件的消息始终按工作输入处理。

完整规则见[数字菜单设计](../design/wechat-menu.md)。

## 管理台拥有的能力

| 领域 | 当前操作 |
| --- | --- |
| 连接 | 查看微信监听与 Codex App Server 健康状态 |
| 工作空间 | 查看白名单、切换新消息的默认工作空间 |
| 线程 | 全量搜索与分页、新建、选择、改名、归档 |
| 会话状态 | 实时查看、打断指定执行、随时切换或新建会话；忙碌时拒绝追加工作 |
| 回复 | 按实际配置选择可用回复模式；整体保存模式与风格 |
| 恢复 | 输入有效期内显式重跑失败或中断请求，新记录关联原请求 |
| 交付 | 查看完整回答、认证下载、按到期时间留存、显式重新投递 |
| 运行态 | 排空、恢复、查看版本和任务计数 |
| 安全 | 启用或解除远程锁定 |

管理台不是远程 Shell，也不允许提交任意目录、命令或环境变量。工作空间始终来自本机配置白名单。

## 已删除的行为

下列输入没有保留兼容解释：`状态`、`取消`、`请求队列`、`线程列表`、`视觉风格`、`交付箱`、`为什么没回复`、`文字版`、微信斜杠命令。它们会像其他文本一样进入 Codex。

旧多位数字编号、自然语言控制意图注册表和 `control-state.json` 均已移除。新菜单使用独立的一页单键协议与收件去重记录；迁移程序不导入旧菜单状态。

## Codex 与桥接器的所有权

Codex 拥有真实线程和轮次。codex-link-clawbot 只保存：

- 受信任工作空间定义和每个绑定者的当前选择；
- 当前目标与尚未解析的会话意图；
- 执行、投递和终态请求记录，以及忙碌拒绝回执；
- 回复模式与视觉风格；
- 冻结回答、产物、独立投递回执和运行状态。

目标线程只是下一条微信消息的目的地，不表示其他 Codex 客户端不能同时运行线程。

实例只启用一个明确选定的绑定。输入、结果与恢复流程见[工作台指南](workbench.md)。
