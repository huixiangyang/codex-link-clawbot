# 个人远程工作台

Codex Link 面向一个明确选定的微信绑定。微信用于提交工作，并以数字菜单选择上下文、管理当前会话和取回结果；网页提供完整搜索与详细管理，CLI 用于本机配置与维护。

本轮已补齐附件准备、打断确认、归档恢复与容量处置，功能边界及尚待实机验收的项目见[功能盘点](../product/feature-review.md)。

发送 `0` 或“菜单”打开大字数字菜单，用 `1–6` 选择首页功能；列表每页四项，`7/8` 翻页，`0` 回首页，`9` 退出。菜单只发送一张图片；图片不可用时使用相同编号的文字。长结果以每页 500 字、按需翻页的方式阅读。参见[数字菜单设计](../design/wechat-menu.md)。

## 开始与继续工作

1. 在网页顶部确认工作空间和当前会话。没有会话时，首条请求自动建立会话。
2. 向微信机器人发送文字、图片或文件。接收回执包含请求编号；请求立即开始处理。
3. 上一轮结束后继续发送消息，沿用同一个会话；正在执行或准备输入时再次下令立即拒绝，显示说明和数字操作菜单。被拒内容不会保存为工作，也不会稍后执行。
4. 网页切换工作空间或新建会话只影响之后提交的请求。当前执行保留原目标和回复偏好，其他会话可以即时开始工作。

当前目标独立于会话列表读取，不会因为它不在第一页而消失。切换目标失败时，原工作空间与会话保持不变。会话页支持搜索、分页、新建、选择、改名、归档；有关联未结束请求的会话不能归档。外部已经归档的会话不能被重新选中或继续执行。

## 请求中心

“进行中”只包含执行和初次投递中的请求；“待处理”包含归档失败、打断未确认、执行失败、中断和投递失败或未确认的请求；“历史”包含无需恢复的已结束请求；“全部”包含所有保留期内记录。列表支持搜索和分页，选择请求可以查看输入、目标、结果和投递记录。

| 情况 | 可用操作 |
| --- | --- |
| 正在执行 | 取消指定请求；进入结果收尾后不再接受取消 |
| 打断未确认 | 刷新会话状态、再次打断或切换会话；不能直接重跑 |
| 执行完成，归档失败 | 恢复保存原回答与文件；不会再次执行 |
| 执行失败或中断，输入未过期 | 显式重新执行，创建关联原请求的新记录 |
| 执行完成，结果未过期 | 查看、复制回答、下载文件、显式重投到微信 |
| 微信投递失败或结果不确定 | 优先取回网页结果；确认后可以重新投递 |
| 结果过期 | 保留执行记录，文件与回答不再可取回 |

执行、归档与投递是独立事实。微信发送失败不会让已经完成的 Codex 工作变成“执行失败”，重新投递不会再次调用 Codex。

重新执行可能重复原轮次已经产生的部分文件修改。重新投递可能在微信中出现重复消息。两种操作都要求确认，并通过操作编号防止网络重试重复创建工作。服务重启后，或超过 24 小时未收到微信消息，请先发送“菜单”更新投递上下文；网页查看和下载不需要微信上下文。

## 保留与容量

| 数据 | 保留规则 | 容量 |
| --- | --- | --- |
| 原始输入、入站附件、消息上下文 | 请求结束后 24 小时 | 全实例有效输入最多 500 MiB，计入文本、上下文和附件 |
| 冻结回答与产物 | 执行完成后 7 天 | 全实例有效结果最多 1 GiB |
| 请求记录 | 请求结束后 30 天 | 每个绑定最多 1,000 条 |

后台每分钟分别清理到期数据；启动和接收时也会检查。输入到期不会删除尚未到期的结果。输入或记录达到上限时拒绝新增；新增执行还会预留最多 105 MiB 结果空间，容量不足时提前拒绝。附件准备预留 100 MiB 输入空间，准备完成后按实际大小结算。网页显示用量、预留及最近到期时间，详情可确认清理输入、结果和记录名额；来源回执保留至原记录的 30 天期限，旧消息不会因此重跑。系统不通过删除未过期结果腾空间。容量是业务有效载荷限额，不包括文件系统开销、工作空间中的 Codex 文件、离线备份或旧迁移副本；这些由本机维护。

回答和文件先持久化，随后尝试投递。下载要求管理令牌，并校验请求归属、登记清单、路径和 SHA-256。输入令牌和私有文件路径不进入详情 API。外部图片链接不属于本机产物，其可用期由源站决定。

## 打断、排空与锁定

- 取消请求：只针对明确的请求编号，不会取消后来开始的其他请求；不撤销已经发生的文件修改。
- 排空实例：停止接收新的工作，让当前工作收尾，用于维护。
- 锁定微信入口：拒绝新的微信工作；当前请求继续，网页结果仍可取回。

默认简洁通知：短答直接发送，超过 500 字或包含文件/图片链接时只发短说明，回复 `0→5` 按需阅读或重发完整结果。首页 `4` 列出运行中会话，查看、打断无需切换输入目标。

设置页按真实配置显示阅读卡、语音能力，并整体保存回复偏好。轮询不会覆盖未提交的偏好和会话表单。阅读卡或语音没有配置时，相应模式不会出现在选项中；API 同样拒绝保存。

语音只发送 MP3，不要求启用图片；长答案读节选并说明如何取回全文。显式选择阅读模式时仍会批量发送阅读卡。

真实微信、Codex 登录、视觉渲染和语音提供商需要在部署环境验收，见[验收清单](../operations/acceptance.md)。
