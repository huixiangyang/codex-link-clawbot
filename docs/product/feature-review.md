# 功能盘点与本轮改造

更新日期：2026-09-23。范围为当前工作区，包含尚未提交的重构，不代表已部署版本。

产品定位：个人通过手机实时使用和管理本机 Codex 会话。数字菜单减少打字；同一会话的新指令只允许即时执行，忙碌时拒绝并给出操作菜单；不同会话可独立执行。没有等待执行、排序或暂停队列。

## 保留的功能与边界

| 功能 | 当前行为 |
| --- | --- |
| 绑定与部署 | CLI 绑定、启动、排空、升级、备份与离线迁移；真实部署另行验收 |
| 工作空间与会话 | 配置目录白名单；新建、切换、搜索、改名、归档；切换不影响原执行 |
| 文字、图片、文件 | 固定会话和偏好，登记后立即执行；附件接收属于可见、可打断的准备阶段 |
| 语音输入 | 使用微信提供的转写；没有转写时明确提示重新发送文字，不提供独立语音识别 |
| 数字菜单 | 0 首页、1–6 选项、7/8 翻页、9 退出；列表每页四项；编号绑定业务对象 |
| 实时会话管理 | 首页 4 查看运行中会话；包含本地准备阶段和可信工作空间内的外部运行会话；管理不切换输入目标 |
| 忙碌拒绝 | 提示提交失败并弹出刷新、打断、切换、新建菜单；拒绝来源有持久回执，不会稍后执行 |
| 打断 | 固定请求或原生轮次；区分请求打断与确认停止；无法确认时显示未知，禁止直接重跑 |
| 结果恢复 | 执行、归档、投递分别记录；执行完成但归档失败时恢复保存原成果，不再次调用 Codex |
| 手机结果取回 | 默认短答直接发送；超过 500 字或包含文件/图片链接时先发短通知；回复 0→5 取回，每次阅读 500 字 |
| 阅读与语音输出 | 用户显式选择后启用；MP3 不依赖配图，长语音明确称为节选；阅读卡仍可批量发送，不是默认模式 |
| 网页请求中心 | 搜索、分页、复制回答、认证下载、查看投递回执、恢复保存、重发、显式重跑和清理 |
| 容量管理 | 输入 500 MiB、结果 1 GiB、每绑定 1,000 条记录；展示用量与最近到期时间；详情可清理内容与记录名额 |
| 锁定与运维 | 锁定入口、排空实例、维护恢复；不会变成用户工作队列 |

网页新建会话立即建线程，微信新建先准备目标、首条工作才建线程。已归档会话没有恢复入口。图片风格与语音提供商是附属能力，不计入核心会话管理的完成度。

## 原盘点 F1–F11 的处理

| 编号 | 原问题 | 本轮处理与剩余边界 |
| --- | --- | --- |
| F1 | 慢附件、渲染、重发阻塞消息入口 | 附件登记后由执行器下载；菜单发送、外部打断与恢复操作独立执行；旧菜单渲染可取消。只读状态与目录查询设置 3 秒上限，消息路由仍按顺序处理 |
| F2 | 上游打断失败仍显示取消 | 查询指定轮次终态；未确认错误传回业务层，显示“打断未确认”；若轮次其实已完成则保留成果 |
| F3 | 保存失败把完成工作变成可重跑失败 | 独立完成事实、回答检查点和归档状态；恢复只取回原轮次及产物；开始前预留结果额度 |
| F4 | 阅读卡指向已删除的“文字版”命令 | 提示改为数字结果菜单，没有恢复旧命令兼容层 |
| F5 | 手机缺少运行中概览、进度无来源 | 首页 4 查看运行会话；目录优先运行项，过程消息带会话及工作空间；查看不改变当前目标 |
| F6 | 无转写语音和不支持消息静默忽略 | 给出短原因、重新发送文字与 0 菜单提示 |
| F7 | 默认批量长输出、语音依赖配图 | 默认简洁通知与按需取回；MP3 独立发送；显式阅读模式保留整批阅读卡 |
| F8 | 重发去重后直接谎报成功 | 同一操作编号返回该次实际回执；失败或未确认不会变成成功，也不会再次发送 |
| F9 | 满额后没有处置入口 | 请求详情可确认清理，释放内容与记录名额；最小执行来源回执保留至原记录的 30 天期限，防止旧来源重跑 |
| F10 | 高级接口半成品、重复焦点与文件库 | 删除无用户入口的高级线程控制、关系图、模型目录、旧输入链路、旧文件库和旧焦点存储；当前目标只由 target 管理；旧格式只在离线迁移器中读取 |
| F11 | 翻页反复全扫、网页逐项 RPC | 目录使用 3 秒有界缓存，网页列表复用目录状态；详情与执行准入读新鲜状态。首次目录仍需扫描，尚未做真实大规模性能验收 |

## 状态与保留规则

输入和入站附件在请求结束后保留 24 小时；结果自执行完成起保留 7 天；历史和清理后的来源回执保留 30 天。新执行预留最多 100 MiB 产物加 5 MiB 回答，待附件请求预留 100 MiB 输入。界面用量包含预留，完成后按实际大小结算。

主动清理需要用户确认，会删除输入、回答、文件和列表记录；最小回执不保存正文、附件、消息令牌。恢复保存不会延长结果保留期，清理后的成果不能恢复。系统不会自动删除未到期结果给新工作腾空间。

离线迁移升级至请求索引 v4、输入清单 v2、结果清单 v2。备份验证成功后，运行目录移除旧项目选择、线程索引和文件库；迁移中断可从校验备份恢复。运行时拒绝旧格式，见[迁移指南](../operations/migration.md)。

## 验证范围

必要回归覆盖慢附件期间的拒绝和打断、打断错误与真实轮次结果、成功执行后的归档故障及恢复、失败重发的重复操作、容量释放后的来源去重，以及目录分页缓存。核心状态规则由真实请求存储与隔离 HTTP/RPC 依赖验证。

手机与桌面网页使用隔离测试夹具检查恢复保存、结果取回、清理确认、忙碌拒绝与会话管理；不连接真实微信或 Codex。完整检查使用 `make check`，部署环境仍须执行[真实渠道验收](../operations/acceptance.md)。首次目录的真实规模性能、微信图片压缩、上下文有效期和语音提供商可用性不由本机隔离测试证明。

实现要求与任务见[本轮规格](../../specs/realtime-completion/requirements.md)，使用路径见[工作台指南](../guides/workbench.md)。
