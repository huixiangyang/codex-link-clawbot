# WeClaw 产品路线

更新日期：2026-08-06

## 产品定位

WeClaw 是“个人微信里的本机 Codex 工作台”。它只支持 Codex 应用服务，不做通用机器人、多模型路由、远程命令行或任意工作目录。

产品先区分 Codex 原生概念：

1. 线程：可以持续、恢复、分叉和归档的对话。
2. 轮次：线程中的一次输入与执行。
3. 技能：Codex 从工作目录和用户环境发现的能力。

项目入口、微信持久请求队列、提示词模板、阅读卡、语音和自动化属于 WeClaw 的增强层，不冒充 Codex 原生概念。Codex 没有 WeClaw 的项目对象；项目入口只负责把受信任目录传给 Codex 作为工作目录。

## 当前基线

| 归属 | 领域 | 已实现 |
| --- | --- | --- |
| Codex | 线程 | 新建、搜索、详情、切换、重命名、分叉、置顶、压缩、目标、归档、恢复、永久删除 |
| Codex | 模型与轮次 | 模型目录、线程级推理强度、真实轮次、追加指令和中断 |
| Codex | 审查与工具 | 未提交改动审查、技能和外部工具连接摘要 |
| WeClaw | 输入与项目入口 | 文字、最多四张图片、受限文件、图片批注、目录白名单和当前目录选择 |
| WeClaw | 请求队列 | 持久先进先出、计划进度、取消、重试和重启恢复 |
| WeClaw | 提示词模板 | 按绑定者和项目入口隔离的模板、顺序参数、创建、编辑、删除和请求复用 |
| WeClaw | 输出与运维 | 自适应文字、五套阅读图、文件与语音交付、诊断、远程锁定、排空和事务部署 |

微信操作总览一次展示六个领域和 44 个稳定编号。每个领域明确标注 `Codex` 或 `WeClaw`；等待中的微信输入称为 WeClaw 请求，只有 `turn/start` 创建的执行才称为 Codex 轮次。

## 当前收口阶段：Codex 对齐

完成标准：

- 所有用户入口、卡片、诊断和文档明确标注 Codex 原生与 WeClaw 增强。
- 控制领域和持久菜单标识使用 `project`、`thread`、`turn`、`queue`；`turn.*` 只表示 Codex 轮次，WeClaw 请求队列只写 `queue.*`。
- 分叉、置顶、压缩、目标、模型、推理强度、轮次追加和代码审查都有协议测试与微信流程测试。
- 旧控制菜单通过离线迁移清空，不在运行时兼容旧动作。
- 完整测试、竞态检查、静态检查和构建通过后，才进入部署。

## 下一阶段一：移动端审查包

目标：让一次编码轮次在手机上可以快速判断“改了什么、是否可靠、下一步做什么”。

- 把代码审查结论、变更文件统计、测试结果、风险和交付物渲染成 1–3 张高质量图片。
- 支持前后截图与并列对比；只访问配置允许的本机预览地址。
- 支持在微信中选择“继续修复”“接受结论”“重新审查”，动作仍进入明确线程。
- 不展示原始差异、终端输出、私有路径、账号或凭据。

完成门槛：一个前端改动可以返回前后截图、测试结论和审查摘要，并从卡片继续同一线程。

## 下一阶段二：自动化关注

目标：用户可以说“接下来一天关注这个项目，异常或恢复时告诉我”。

- 微信内创建、查看、暂停、恢复、修改和删除关注。
- 只允许项目配置声明的 Git、服务和健康检查，不接受自由命令或自由网址。
- 异常、恢复和变化按指纹去重，多项变化合并通知。
- 定义、游标和回执按绑定者及项目隔离，重启后继续。

完成门槛：一个关注完整经历正常、异常、恢复、暂停、重启和过期，微信通知次数与状态一致。

## 下一阶段三：显式项目记忆

目标：只在用户明确收藏时保存长期内容。

- 收藏最近回答、审查包或交付物引用。
- 支持项目内搜索、标签、取消收藏、重新发送和在新线程继续。
- 未收藏回答不进入长期状态；失效交付物显示明确状态。

完成门槛：收藏内容重启后仍可检索，跨绑定者和跨项目不可见。

## 候选功能

| 候选 | 价值 | 前置条件 |
| --- | --- | --- |
| 线程树图片 | 在手机上查看分叉关系、当前分支和目标 | 线程分叉与删除稳定运行 |
| 项目仪表卡 | 一张图查看分支、技能、外部工具、最近执行结果和健康 | 自动化关注状态稳定 |
| 交付箱 | 集中查看最近图片、文件、审查包和失效时间 | 审查包统一交付引用 |
| 轮次通知策略 | 只在阶段真正变化时通知，减少进度噪声 | 自动化通知合并机制 |
| 本机配置体检 | 离线检查浏览器、语音、Codex 和系统服务前提 | 当前部署流程稳定 |

## 明确不做

- Claude、Gemini、Kimi 或多模型提供商路由。
- 多智能体产品概念和跨智能体线程。
- 任意工作目录、任意命令或任意网址自动化。
- 未经确认的提交、推送或部署。
- 群聊协作、默认永久记忆、伪原生语音气泡。
- 旧斜杠命令、旧中文“会话/任务”入口和运行时兼容层。

## 功能进入规则

每个新功能必须先回答：属于 Codex 原生线程/轮次/工具，还是 WeClaw 项目入口/请求队列/交付层；失败和部分成功如何展示；状态由谁拥有、保存多久；是否扩大文件、网络或凭据边界；如何自动测试、真机验收和回滚。无法明确回答时，不进入操作总览。
