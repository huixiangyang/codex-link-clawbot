# 微信文件、交付物与定时巡检

## Turn 私有目录

每条进入 Agent 的任务统一创建：

```text
~/.weclaw/turns/turn-*/
├── inbox/
└── outbox/
```

根目录、turn 目录和两个子目录权限均为 `0700`，入站文件权限为 `0600`。消息桥接器持有目录生命周期：最终文字与附件发送完成后删除；下载失败、Agent 失败或 `/cancel` 取消时同样删除。

这是破坏性的新边界。系统不再从 Agent 回复中解析裸绝对路径，也不会发送工作区中的任意现有文件。

## 微信文件输入

处理器从 iLink `FileItem` 读取文件名、明文大小和 CDN 加密信息，在 60 秒下载期限内完成 AES-128-ECB 解密，然后按实际内容和扩展名双重校验。

约束：

- 单条消息最多 8 个文件。
- 单个文件最大 50 MiB。
- 图片与文件合计最大 100 MiB。
- 支持 PDF、ZIP、TAR、GZip、文本、日志、Markdown、JSON/YAML、补丁和常见源代码。
- 拒绝 ELF、PE 可执行文件、伪装 PDF/ZIP/GZip、扩展名不在白名单内的文件，以及文本扩展名下包含 NUL 字节的二进制内容。
- ZIP/TAR 不自动解压，任何入站脚本都只作为不可信数据交给 Agent，不由桥接器执行。

Codex 接收的提示中明确包含文件名、探测到的内容类型、大小和本机绝对路径。纯文件消息自动使用文件检查指令；文字与文件同时发送时保留用户原始指令。

## Agent 交付物回传

每次 turn 的提示都会告诉本机 Agent 专属 `outbox` 绝对路径。Agent 需要回传文件时，只把最终交付物写入该目录。任务结束后，处理器递归扫描常规文件并按顺序上传微信 CDN。

允许的交付物包括 PDF、Office 文档、ZIP/TAR/GZip、补丁、文本、日志、Markdown、CSV、JSON/YAML、图片和 MP4/MOV。单次最多 8 个、单个最大 50 MiB、总计最大 100 MiB；符号链接和不支持的类型拒绝发送。成功与失败结果都会追加到最终微信文字。

多 Agent 广播时，每个 Agent 获得独立子目录，防止并行写入和重复发送。

## 每日项目巡检

`scheduled_reports` 中每项代表一个每日计划。调度器每分钟检查一次，并在配置时区内到达 `daily_at` 后运行。若服务当天在设定时间之后才启动，会立即补发。

采集内容：

- 当前 Git 分支或 detached HEAD。
- 未提交改动数量。
- 相对上游的领先和落后提交数。
- `commit_lookback_hours` 时间窗口内最多 8 条提交。
- `systemctl --user is-active` 返回的服务状态。
- HTTP 健康端点的状态码和最多 256 字节响应摘要。

这些信息直接来自本机命令和 HTTP 响应，不提交给 Agent。服务名经过字符白名单校验，Git 命令使用参数数组执行，不经过 shell。

发送目标是每个已登录 iLink 凭据中的绑定者。去重键由“报告名 + 绑定者 + 本地日期”组成，成功后原子写入 `~/.weclaw/scheduled-reports-state.json`。发送失败不会记账，下一分钟自动重试。
