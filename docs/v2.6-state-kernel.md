# v2.6 统一状态内核实现

## 1. 已实现范围

`statefile` 是运行状态唯一的通用 JSON 文件内核。偏好、项目选择、远程锁、会话索引、自动化、素材库、微信同步游标、任务索引、冻结结果、配置与账号凭据已经删除各自的临时文件写入器，统一使用这一内核。

任务附件仍先写入唯一 staging 目录，再以整目录改名提交；部署候选、systemd 单元和回滚快照也保留专用事务。这些对象不是可独立覆盖的 JSON 状态，不能降级为普通状态文件写入。

## 2. 文件事务

每次覆盖依次执行：

1. 检查所有已存在路径祖先，拒绝符号链接；收紧目标目录为 `0700`。
2. 拒绝非普通目标，并清理只属于该目标的遗留事务文件。
3. 在同目录创建 `0600` 临时文件，写入格式化 JSON 并执行文件 `fsync`。
4. 对旧目标建立同目录私有硬链接备份，然后原子替换目标。
5. 执行父目录 `fsync`；若失败，恢复旧目标并再次同步目录。
6. 提交成功后删除短期备份。下次写入会清理崩溃遗留的临时项。

不可变请求和首次冻结结果使用 `CreateOnly`，已存在目标按 `conflict` 拒绝，不能静默覆盖。

严格读取使用 `O_NOFOLLOW`，限定最大字节数，拒绝未知字段和尾随数据，并在领域校验器通过后才交给调用方。所有状态文件收紧为 `0600`。

## 3. 稳定错误分类

调用方只依赖以下分类，不解析系统错误文案：

- `schema`：版本、字段、枚举、领域不变量或尾随数据错误。
- `permission`：符号链接、非普通文件、不安全根目录或权限错误。
- `capacity`：文件、负载、磁盘配额或空间上限。
- `corrupt`：截断 JSON、语法损坏、清单大小或 SHA-256 不一致。
- `conflict`：运行时与迁移互斥、不可变文件已存在。
- `unavailable`：其他暂时无法完成的系统 I/O。

本机诊断可以记录操作与路径；微信展示层只能使用分类和安全说明。

## 4. 生命周期锁

服务启动后持有 `~/.weclaw/.state.lock` 的非阻塞独占锁，直到进程退出。离线迁移必须获取同一把锁：

- 服务运行时执行迁移，立即返回 `conflict`。
- 部署器必须先排空并停止服务，迁移才可能开始。
- 锁文件不进入部署快照；它不保存状态，进程退出后内核锁自动释放。

进程内相同路径还复用一把读写锁，避免多个领域实例交错覆盖。

## 5. 账号凭据破坏性迁移

账号文件从无版本结构升级为严格 v1，并新增必填 `version: 1`。加载时不再静默忽略损坏文件：未知字段、错误版本、缺失令牌、非 HTTPS 服务地址、文件名与机器人 ID 不一致都会阻止启动。

`weclaw deploy` 停服后的离线迁移会把已知的无版本结构一次性转换为 v1。运行时没有旧格式兼容分支，也没有双写。手工替换二进制而跳过部署事务会被明确拒绝。

## 6. 清单与故障验证

内核可以为明确列出的私有文件生成稳定路径、大小和 SHA-256 清单，复制后必须重新校验。清单不会遍历未声明路径。

测试分别在写入、文件同步、改名和目录同步边界注入失败，并证明旧文件仍可严格读取；同时覆盖符号链接祖先、容量、未知字段、截断 JSON、事务孤儿、并发运行时/迁移锁、凭据迁移和清单篡改。

```bash
go test ./statefile ./config ./preference ./project ./session ./reporting ./ilink ./taskqueue ./messaging ./cmd
go test -race ./statefile ./taskqueue ./messaging ./ilink ./api ./cmd
```

## 7. 下一步边界

持久菜单 revision 将直接使用本内核，但在类型化 Action 与 Controller 建立后实现。当前 `Handler` 中的内存菜单不是新内核的一部分，将在 v2.6 后续批次中整体删除，不增加过渡双写。
