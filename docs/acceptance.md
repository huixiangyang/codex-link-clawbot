# 微信端验收清单

## 1. 项目与主菜单

1. 空闲时发送 `/`，应只显示“项目、会话、最近任务、更多功能”四个主入口，并显示当前项目。
2. 发送“项目”，应列出配置项目、当前标记、项目目录和项目内会话数量。
3. 切换到另一个项目后，会话列表不得出现原项目会话；切回后恢复原项目当前会话。
4. 进入“快捷任务”并选择一项，应立即执行配置提示，不要求再次输入。
5. 任意“切换工作目录”旧操作不得执行；配置中的 `codex.cwd` 必须导致启动失败。

## 2. 会话与任务

1. 分别验证会话新建、搜索、详情、切换、重命名、归档和恢复，分页返回应保留页码与搜索词。
2. 启动一个长任务后发送 `/`，主入口应变为“任务状态、暂存下一条指令、当前会话、更多功能”。
3. 运行中发送普通文字，应确认已暂存；任务完成后自动开始该指令。第二条不得覆盖第一条，“清除暂存”应释放槽位。
4. “任务详情”应显示项目、会话短编号、用时和可用的 token 用量，不显示回答正文或私有路径。
5. “运行中心”应显示项目目录、Codex PID，以及收到事件后主/次额度使用率。

## 3. 自动化

1. 发送“自动化”，应显示计划、最近下次运行和分页。
2. 详情应显示项目、周期、时区、检查组合、通知策略、上次运行和上次通知。
3. “立即检查”应直接读取 Git/systemd/HTTP，并返回视觉结果卡；不能调用 Codex 自由执行。
4. 分别验证 `always`、`anomaly`、`change`、`anomaly_or_change`，相同指纹不得误报变化。

## 4. 素材、交付与图片

1. 发送纯链接，Linkhoard 保存成功后“链接素材”应出现记录。
2. 要求 Codex 生成文件，微信收到后“交付记录”应出现私有副本；原 turn 目录删除后仍能“再次发送”。
3. 发送图片并写“批注这张图”，Codex 应收到图片批注契约并在 outbox 生成新的 PNG，不覆盖原图。
4. 长回复仍按所选刊物、构筑、黑标、可爱或简洁风格生成移动阅读卡；“文字版”可取回全文。

## 5. 锁定与语音

1. 配置解锁码后发送“远程锁定”，活动任务应取消、暂存应清除，后续文字/图片/文件均不得进入 Codex。
2. 错误解锁码不得改变状态；`解锁 正确码` 后恢复。
3. 配置 MiMo TTS 后发送“语音简报”，应由 `/chat/completions` 合成并收到 `ItemTypeVoice` 的 MP3 语音消息；网关 4xx/5xx、无音频、非法 Base64、非 MP3 和超限响应都应明确回退错误文字。
4. `voice.command` 必须作为未知字段拒绝；日志、微信错误消息和仓库均不得出现 `voice.api_key` 的值。

## 6. 安全与部署

1. 非绑定者、群聊和未知联系人消息必须拒绝。
2. `session-index.json` 必须为 v3，`task-history.json` 必须为 v2；旧 schema、未知字段和尾随数据必须拒绝启动。
3. `project-state.json`、`automation-state.json`、`library.json`、`remote-lock.json` 和交付副本均不得宽于 `0600/0700`。
4. 执行：

```bash
go test ./...
go test -race ./codex ./messaging ./session ./config ./reporting ./project ./visual
go vet ./...
```

5. 部署后确认 systemd 服务为 `active`、`/health` 返回成功，并从微信完成项目切换、普通 Codex turn、自动化手动检查和交付物再次发送。
