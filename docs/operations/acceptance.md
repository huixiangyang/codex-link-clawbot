# 验收清单

## 自动检查

```bash
make check
```

至少应通过：文档链接、Go 格式、`go vet ./...`、race 测试和二进制构建。

## 管理台

- [ ] 服务只监听 `127.0.0.1:18120` 或另一个回环地址。
- [ ] 无令牌访问 `/api/snapshot` 返回 401。
- [ ] 页面响应包含 CSP、`DENY` frame 和 `no-referrer`。
- [ ] 错误令牌不会留在页面，正确令牌仅存在当前标签页。
- [ ] 总览显示微信、Codex、工作空间和目标线程状态。
- [ ] 可以切换工作空间、新建线程并选择目标。
- [ ] 可以暂停/继续队列、置顶/删除等待任务、取消当前任务。
- [ ] 回复模式和视觉风格刷新后保持。
- [ ] 排空/恢复和远程锁定状态正确。
- [ ] 1440×900 与手机宽度下没有遮挡、横向溢出或不可达操作。

## 微信

- [ ] 非绑定者消息被忽略。
- [ ] `菜单` 返回连接摘要和管理地址，不返回数字菜单。
- [ ] 普通文字先确认入队，再收到 Codex 结果。
- [ ] `状态`、`取消`、`1` 和 `视觉风格` 作为普通 Codex 请求。
- [ ] 图片和受支持文件进入当前目标并在执行后清理临时副本。
- [ ] 重复来源消息不重复下载附件或执行任务。
- [ ] 远程锁定后消息不会进入 Codex，只返回管理入口。

## 部署

- [ ] 配置是 schema 7，`codex-link-clawbot config` 成功。
- [ ] `management-token` 是常规文件且权限为 `0600`。
- [ ] `codex-link-clawbot status` 返回 ready。
- [ ] HTTPS 公网域名转发到回环端口，应用端仍要求令牌。
- [ ] `control-state.json` 已被迁移删除。
