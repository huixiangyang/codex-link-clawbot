# 验收

本页定义如何验收，不记录某次开发或服务器已经通过。每次交付注明源码版本、程序版本、目标环境、执行步骤、结果与未覆盖项；本地测试、真实渠道和部署必须分别确认。

## 本地自动检查

```bash
make check
```

包含文档链接、Go 格式、vet、全量 race 测试和本机构建。协议或输入解析变更再运行 `make fuzz-smoke`；仅文档修改至少运行 `make docs-check` 和 `git diff --check`，核对命令、链接锚点、配置示例和接口是否匹配源码。

视觉测试在缺少 Chromium 时可能跳过。必须区分“测试命令退出成功”和“实际完成渲染”，不能仅凭构建通过宣称界面可用。

## 隔离业务与界面

使用[开发夹具](../guides/development.md#隔离预览)，不连接真实账号。至少检查桌面 1440×900 和手机 390×844；菜单检查 320 px 宽度和 192 px 缩略图。

- [ ] 未认证 API 返回 401，错误令牌可重新输入，私有内容不进入 URL、日志或非认证页面。
- [ ] 长名称、长回答、空状态、错误状态和分页没有遮挡、横向溢出或不可达操作。
- [ ] 当前目标即使不在第一页仍可见；失败切换保持原选择，自动刷新不覆盖未提交表单。
- [ ] 工作空间、会话、请求和产物的搜索、分页、详情、返回路径可用；菜单编号始终对应展示时对象。
- [ ] 未配置的能力不能保存；偏好失败不出现部分更新。
- [ ] 外部所有者的结果、到期结果、目录外文件和符号链接不能下载。
- [ ] 附件缺失不遮蔽有效文字，完好文件可单独下载；被篡改文件不可下载，完整执行与投递仍拒绝损坏附件。
- [ ] 首次投递回执与终态事务失败时都不前进，重复来源和操作编号不产生第二次工作。

涉及数据迁移或部署时使用临时状态根和模拟依赖，验证失败回滚及不受管文件不被删除，不对生产目录做故障注入。

## 真实微信与 Codex

以下步骤会连接实际账号、执行 Codex 或发送消息，应在明确选定的测试绑定和可控项目中执行；涉及重启和损坏测试先使用隔离实例。

- [ ] 首条文字建立会话，结束后追问沿用；快速请求只发送最终回答，不带固定回执、编号或操作尾巴。
- [ ] 慢请求从准备阶段计时，超过配置阈值只提示一次；真实阶段仍在网页更新，完成、失败或取消后不再推送等待提示。
- [ ] A 执行时切换到 B，A 不改变目标或结果归属，完成消息保留 A 的来源；迟到的线程创建不抢回选择。
- [ ] 同一会话准备或执行期间第二条工作被拒绝，拒绝来源稍后重投也不补执行；其他会话可独立工作。
- [ ] 图片和文件不自动执行，补充要求并显式提交后才下载；切换不能转移草稿，失效或重启不自动提交。
- [ ] 慢附件、渲染和重发期间仍能打开菜单；准备阶段可打断，取消后不进入 Codex。
- [ ] 上游未确认停止时显示未知，不标记取消或允许危险重跑；若轮次已完成则保留成果。
- [ ] 从旧页面取消已结束请求 A 不打断后来开始的 B，结果收尾阶段拒绝取消。
- [ ] 首页活跃预览倒序、去重、最多三项；会话状态列表不改变输入目标，锁定页不泄漏预览。
- [ ] 单独的 `#` 或 `/` 打开首页，`#数字` 选择、翻页、过期与重投正确；裸数字作为工作内容，解锁码不进入工作或草稿。
- [ ] 新用户完整文字分段正确；已有偏好不覆盖，简洁通知和长语音明确说明节选。
- [ ] `全文`、`文件`、`继续会话` 及重发确认绑定正确结果，不触发意外新执行。
- [ ] 可选阅读图真实渲染并经微信压缩后仍可读；MP3 真正合成并发送，语音不依赖图片，无转写输入得到明确提示。

## 异常与恢复

- [ ] Codex 成功但归档失败时保留完成事实，只能恢复保存，不重复修改项目。
- [ ] 微信投递失败或不确定时网页仍可取回；重复重投编号返回原状态，不谎报成功、不再次发送。
- [ ] 没有新鲜微信上下文时重投给出明确提示，网页下载不受影响。
- [ ] 旧部署成功通知被清理；失败或结果待取回通知保留，补送成功后不会在每条新消息前重复出现。
- [ ] 执行中重启标记中断，发送中重启保留成果并标记待确认，均不自动重跑或重投。
- [ ] 输入、结果、历史分别到期；恢复和重投不延长期限，输入到期不删除有效结果。
- [ ] 容量计入在途预留，达到上限明确拒绝；主动清理释放名额并保留来源去重，不删除用户工作目录。
- [ ] 多凭据未选择时拒绝启动；切换绑定需停服，管理台只能看到当前绑定的数据。

## 部署验收

- [ ] 候选来自明确源码或不可变 Release，校验和、版本和平台相符，没有使用浮动“latest”替代版本记录。
- [ ] 服务使用专用普通账号，配置和凭据正确，只有一个实例持有运行锁。
- [ ] SQLite 状态就绪，无旧运行 JSON 或未完成导入；库、WAL/SHM、附件及日志权限符合约定。
- [ ] 管理只监听回环，HTTPS 代理正确，令牌仍必需，数据库和 Unix socket 没有公开。
- [ ] 排空阻止新工作并等待已接收工作，候选以排空模式健康后才恢复准入。
- [ ] 提交前失败能恢复旧版本；提交不确定时不覆盖可能已消费新消息的数据，回执与实际状态一致。
- [ ] `status` 的运行版本与候选一致，Codex ready、微信监听健康，网页读取下载和一条真实任务均通过。
- [ ] 部署回执落盘、网页版本状态更新，部署成功不产生微信待发通知。
- [ ] 日志可读、脱敏与轮转正常；部署业务快照按结果清理，必要离线备份仍安全保留。

交付结论分别列出：本地检查、隔离视觉、真实渠道、提交推送、实际部署。未执行的项目直接标为未验证，不沿用历史“已通过”结论。
