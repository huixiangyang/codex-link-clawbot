# 验收清单

## 自动检查

```bash
make check
```

至少应通过：文档链接、Go 格式、`go vet ./...`、race 测试和二进制构建。

## 管理台

- [ ] 服务只监听 `127.0.0.1:18120` 或另一个回环地址。
- [ ] 无令牌访问 `/api/snapshot` 返回 401。
- [ ] 页面响应包含 CSP、`DENY` frame 和 `no-referrer`。
- [ ] 错误令牌不会留在页面，正确令牌仅存在当前标签页。
- [ ] 设置与顶部上下文显示微信、Codex、工作空间和目标线程状态。
- [ ] 可以切换工作空间、新建线程并选择目标。
- [ ] 无队列入口；同一会话忙碌时第二条指令明确失败并显示数字操作菜单。
- [ ] 回复模式和视觉风格刷新后保持。
- [ ] 排空/恢复和远程锁定状态正确。
- [ ] 1440×900 与手机宽度下没有遮挡、横向溢出或不可达操作。

- [ ] 上一轮结束后继续同一会话；执行中可切换目标，原执行继续且可精确打断。
- [ ] 执行完成、微信发送失败时，网页仍能读取回答并下载文件。
- [ ] 重跑生成新记录，重投不调用 Codex；重复操作编号不产生额外执行或投递。
- [ ] 输入、结果、记录分别按 24 小时、7 天、30 天清理。
- [ ] 超过一页的请求、会话和文件都可取回；自动刷新不覆盖未提交表单。

本次隔离验证的已执行项目见[验证记录](business-validation.md)。以下微信与部署项需要真实环境完成。

## 微信

- [ ] 非绑定者消息被忽略。
- [ ] `0` 打开单图数字菜单；`1–6` 首页选择、`7/8` 翻页、`0` 首页、`9` 退出在手机端可用。
- [ ] 不放大图片仍能识别数字与主要选项；列表最多四项，长结果用数字按需翻页。
- [ ] 新建与切换会话、实时状态与打断、结果取回和设置直接在微信完成。
- [ ] 打断、重跑和重投确认绑定具体请求或轮次，列表变化不影响目标；旧编号与重复消息不会执行另一个操作。
- [ ] 图片失败才回退文字；锁定可通过数字菜单进入解锁码输入，解锁输入不会成为 Codex 请求。
- [ ] 普通文字先收到执行回执，再收到 Codex 结果。
- [ ] `状态`、`取消` 和 `视觉风格` 作为普通 Codex 请求；`1` 在菜单内选择选项，显式退出菜单后才作为普通请求。
- [ ] 图片和受支持文件进入当前目标，输入在结束后 24 小时到期清理。
- [ ] 重复来源消息不重复下载附件或执行任务。
- [ ] 远程锁定后消息不会进入 Codex，只返回管理入口。

## 部署

- [ ] 配置是 schema 7，`codex-link-clawbot config` 成功。
- [ ] `management-token` 是常规文件且权限为 `0600`。
- [ ] `codex-link-clawbot status` 返回 ready。
- [ ] HTTPS 公网域名转发到回环端口，应用端仍要求令牌。
- [ ] `control-state.json` 已被迁移删除。

- [ ] 多凭据实例已经通过 `binding select` 选择唯一入口。
- [ ] 请求索引已迁至 v4、输入与结果清单为 v2，`targets.json` 与迁移备份存在，未完成迁移标记不存在。

## 当前缺口的修复验收

这些项目尚未通过，具体证据见[功能盘点](../product/feature-review.md)。

- [ ] 慢附件接收或结果重发期间，仍能及时响应手机会话操作；准备阶段可见且可打断。
- [ ] 上游拒绝或超时的打断不会被记录为已取消；只有确认原轮次停止后才显示完成。
- [ ] Codex 成功后结果保存失败，仍保持执行成功事实，提供取回或恢复保存操作。
- [ ] 阅读卡不会提示发送已删除的控制命令；按提示操作能取回原结果且不启动新执行。
- [ ] 手机列表可识别运行中的会话，过程消息能辨认来源；无转写语音收到明确说明。

## 本轮异常与手机验收

- [ ] 慢附件下载期间回复 0 可打开菜单，重复工作立即失败；打断后附件停止且没有进入 Codex。
- [ ] 上游打断失败显示“未确认”；确认停止后才显示取消，轮次实际完成时成果仍保留。
- [ ] 归档失败显示“执行完成，待保存”，只能恢复保存，恢复不会重复修改项目。
- [ ] 默认长答与文件只发短通知，0→5 可分页阅读、重发原成果；阅读卡不再提示旧命令。
- [ ] 运行中会话列表包含其他会话，管理它们不改变当前输入目标；过程消息来源可区分。
- [ ] 详情清理可释放内容与记录名额；同一旧消息再次投递不会重跑。
- [ ] 语音无转写时有明确反馈；语音输出不依赖图片，长答案准确说明是节选。
