# 微信视觉操作卡片

## 目标与范围

微信端的菜单、会话列表、会话详情、任务状态、运行信息、输入提示、确认、成功和错误结果统一显示为纵向 PNG 卡片。卡片宽度固定为 1080 像素，高度根据内容在 900–2400 像素之间计算，适合手机和平板直接阅读。

WeClaw 自己生成的结构化控制结果始终使用固定操作卡片。达到配置阈值的 Codex 最终回答会先被解析成受限的标题、段落、列表、引用、分隔线和代码块，再分页进入独立阅读模板；Codex 返回的 HTML、Markdown 原文或网页地址都不会作为 HTML 进入浏览器执行。

微信图片本身不可点击，因此交互仍由现有两分钟状态机完成：

1. 用户发送 `/` 或自然语言控制意图。
2. WeClaw 生成结构化卡片并上传微信 CDN。
3. 有数字选项或待输入内容时，再发送一条短文字提示。
4. 用户回复数字、名称或路径，WeClaw 在原控制状态中继续处理。

## 视觉系统

卡片使用统一的深色画布、实验性网格和高对比信息排版，并按语义切换强调色：

| 类型 | 场景 | 强调色 |
| --- | --- | --- |
| `home` | 主控制台 | 荧光绿 |
| `session` | 会话与线程 | 靛蓝 |
| `progress` | 活动任务 | 青色 |
| `system` | Codex 与工作目录 | 金色 |
| `success` | 已完成操作 | 薄荷绿 |
| `warning` | 确认、错误和阻塞 | 珊瑚色 |

界面图标使用内联 Lucide 路径，不依赖图标字体、表情符号或外部资源。模板使用本机 Noto CJK 字体并提供系统回退。

## 渲染链路

渲染器优先发现 `~/.cache/ms-playwright` 中最新的 Chromium 或 Chromium Headless Shell，其次尝试系统 Google Chrome。也可以在配置中写明绝对路径：

```json
{
  "visual": {
    "enabled": true,
    "browser_command": "/absolute/path/to/chrome",
    "long_replies": true,
    "long_reply_min_runes": 900
  }
}
```

对应环境变量是 `WECLAW_VISUAL_BROWSER`。推荐安装方式：

```bash
npx playwright install chromium
```

Snap Chromium 使用私有挂载命名空间，无法稳定访问 WeClaw 的渲染文件，因此不会被自动发现，显式配置时也会被拒绝。视觉功能默认开启；没有可用浏览器时服务拒绝启动。明确设置 `"enabled": false` 后，所有控制结果只发送原文字。

每张卡片的处理流程如下：

```text
控制文本
  → 结构化 Card
  → html/template 自动转义
  → 私有 HTML + Chromium profile
  → 1080px PNG
  → 微信 CDN 加密上传
  → 删除整个本次渲染目录
```

渲染并发上限为 2，单次超时 12 秒，PNG 上限 12 MiB。图片生成失败或 CDN 上传失败时，处理器自动发送原始完整文字，控制状态不会丢失。

## 长回复阅读模式

达到 `long_reply_min_runes` 的最终回复会生成 1–10 张阅读卡片。第一个 Markdown 标题可成为整组卡片标题；正文按视觉容量分页，标题不会孤立在页面末尾，代码块保持换行和等宽字体。图片全部送达后发送一条简短说明，30 分钟内回复“文字版”“查看原文”或“复制原文”可取得最近一次完整可复制回复。

超过 40000 个 Unicode 字符、预计超过 10 页、关闭 `long_replies` 或浏览器不支持文档模板时，回复直接保持文字。多页会先完成全部本机渲染再开始上传；若中途网络失败，完整文字会作为兜底发送。

## 安全边界

- 两套模板都编译进二进制，只接受预定义字段；不存在任意模板或任意 HTML 接口。
- 所有动态文本由 Go `html/template` 自动转义。
- Markdown 只解析受限的展示结构，不启用内嵌 HTML、脚本、远程样式或 iframe。
- 页面 CSP 为 `default-src 'none'`，不包含 JavaScript，也不加载外部字体、样式或图片。
- Chromium 启动时关闭后台网络，并把所有主机名解析到不可达地址。
- 渲染根目录权限为 `0700`，HTML 和 PNG 权限为 `0600`。
- 每次渲染使用独立目录和独立浏览器 profile；上传成功、失败或上下文取消后全部删除。

## 验证

```bash
go test ./visual ./messaging ./config
go test -race ./visual ./messaging
go vet ./...
```

部署后在微信依次验证 `/`、`1`、`会话列表`、`下一页`、`状态`、`Codex 信息`、`归档当前会话` 和一条超过阈值的长回复。预期图片先到达；存在选项或待输入内容时，紧随一条简短文字说明；长回复可用“文字版”取回。临时目录 `~/.weclaw/renders` 中不应残留 `card-*` 或 `document-*` 目录。
